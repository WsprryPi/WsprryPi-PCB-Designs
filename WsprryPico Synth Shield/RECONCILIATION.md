# QRP module and Pico synth shield reconciliation

The photographed QRP Labs modules are the circuit reference for **WsprryPico Synth Shield**. The completed [QRP electrical models](../QRP%20Labs%20Modules/README.md) describe the observed hardware; the [shield notes](TCXO-SI5351A-DESIGN.md) describe a proposed implementation around the selected 25 MHz KDS oscillator and Si5351A. The shield's KiCad schematic and PCB still contain only its Pico interface.

This record combines the two chats on 2026-10-06. It preserves the user's preference for Hans Summers' documented circuitry and the existing GPIO shield rename. The user subsequently selected the discrete KDS reference assembly, direct 3.3 V I²C on GP4/GP5, the TI TPS7A2033PDBVR regulator with EN tied to IN for an always-on clock supply, a three-pad input selector defaulting to Pico pin 40, a 1 nF C0G/NP0 prototype coupling capacitor, the local supply-bypass values below, 2.2 µF X7R regulator input/output capacitors and two 4.7 kΩ, ±1% prototype I²C pull-ups supplied from `SYNTH_3V3`. The onboard BS170 amplifier with independent `AMP_EN`, optional-GPS calibration hardware and target bands from 2200 m through 2 m, including WSPR on 2 m, are also selected. Remaining GPIO assignments, bus-speed/rise-time validation, complete passive component specifications and implementation/measurement acceptance stay open.

## Agreed design intent

- Target the amateur bands from **2200 m through 2 m**, including **WSPR on 2 m**, as explicitly confirmed by the user on 2026-10-06. Retain the selected **25 MHz** reference. The newer U4B documentation supplies the relevant Hans/QRP Labs precedent; the older U3S-specific warning does not establish a universal 25 MHz hardware prohibition. See the [checked source comparison](TCXO-SI5351A-DESIGN.md#2-m-wspr-and-the-25-mhz-reference). Validate this shield's synthesis, reference continuity, amplifier and filters across the range; its implementation and measured acceptance remain open.
- Source selected components from **LCSC stock**, as required by the user on 2026-10-06. Record exact manufacturer ordering codes and LCSC C-numbers, and recheck inventory at BOM completion and ordering. A listed part with no inventory does not satisfy the requirement. The 27 MHz availability investigation has not changed the selected 25 MHz reference.
- Use **25 MHz**, with a configured reference of **25,000,000 Hz**, for this shield.
- Retain **Si5351A in MSOP-10** as the shield's synthesizer authority. The photographed Rev6 board's **MS5351M** remains part of that board's model.
- Fit **KDS/Daishinku DSB321SDN, 1XTW25000MAA, LCSC C253672** directly on the shield. The user locked this reference assembly on 2026-10-06 by selecting option 2, the bare selected KDS oscillator, rather than the complete QRP Labs TCXO daughterboard. Complete passive component specifications, placement and physical validation remain open.
- Feed the reference into **XA, pin 2**, through the selected reference circuit's single intended AC-coupling path. Leave **XB, pin 3**, unconnected and omit the 27 MHz crystal.
- Fit **C22 = 1 nF C0G/NP0** between the TCXO output and XA for the first prototype, as locked by the user on 2026-10-06. This follows the selected KDS oscillator's measurement-circuit coupling value. Package, voltage rating, tolerance and supplier part remain open; production acceptance requires loaded XA amplitude and startup verification. Hans' photographed C102 value remains unknown.
- Fit **C21 = 10 nF X7R** at the TCXO supply, **C23 = 100 nF X7R** as its additional local bypass, and **C31/C32 = 100 nF X7R each** at Si5351A VDD/VDDO. The user locked these four prototype values on 2026-10-06. C21 follows KDS' measurement-circuit value, C31/C32 follow Skyworks' supply guidance, and C23 is an additional shield bypass. Packages, voltage ratings, tolerances and supplier parts remain open; supply/startup/RF validation is still required.
- Fit **2.2 µF X7R each** at the regulator input and output for the prototype, as locked by the user on 2026-10-06. These supplement the chip-local bypass capacitors. Annotation, packages, voltage ratings, tolerances and supplier parts remain open; verify effective capacitance, ESR, layout and startup/load behavior against TI's requirements.
- Use **direct 3.3 V I²C** between the Pico and Si5351A, with SDA/SCL pull-ups to 3.3 V and no BSS123 level converters. The user locked this interface on 2026-10-06 by selecting option 1. Supply sequencing remains open.
- Use **I²C0 on GP4 SDA / GP5 SCL**, as locked by the user on 2026-10-06. Connect Pico physical **pin 6 to U31 SDA pin 5** and **pin 7 to U31 SCL pin 4**. Reserve the two GPIOs together for the bus, following the [firmware pin-assignment contract](https://github.com/WsprryPi/WsprryPico/blob/devel/docs/pin-assignment-contract.md), with no simultaneous direct Pico RF-output GPIO. Other GPIOs, bus speed and firmware integration remain open; the starter wiring is unchanged.
- Supply **both SDA/SCL pull-ups from `SYNTH_3V3`**, the clock regulator output, as locked by the user on 2026-10-06. I²C communication requires the synth supply to be on. While it is off, leave the Pico SDA/SCL pins undriven and disable their internal pull-ups. Check any other connected bus device or pull-up supply before approving shared-bus operation; power-off behavior remains a validation requirement.
- Fit **two 4.7 kΩ, ±1% I²C pull-up resistors**, one each on SDA and SCL, for the prototype, as locked by the user on 2026-10-06. This adapts the QRP model's documented 1 kΩ pull-ups to the selected direct 3.3 V interface. Package and ordering code remain open; select bus speed and verify rise time with the actual bus loading before production acceptance.
- Use a **dedicated low-noise 3.3 V linear regulator**, fed through the selected input selector, to generate `SYNTH_3V3` for the TCXO and Si5351A VDD/VDDO. The user locked this power architecture on 2026-10-06 by selecting option 1. Keep this regulator output separate from the Pico's 3V3 output. Low noise is a design requirement, not a measured result.
- Fit **Texas Instruments TPS7A2033PDBVR**, fixed 3.3 V, **SOT-23-5 / DBV**, supplier identifier **LCSC C2862740**, as locked by the user on 2026-10-06. Use the verified pin map in the shield notes. Support components, load/thermal budget and power sequencing remain open; the manufacturer's 300 mA rating does not establish the assembled shield's available current.
- Connect regulator **EN, pin 3**, directly to its own **IN, pin 1**, as locked by the user on 2026-10-06. The TCXO and Si5351A stay powered whenever the selected input supply is available. This supersedes the earlier `SYNTH_EN` GPIO and external 100 kΩ EN pull-down selection; remove those requirements and their GPIO/procurement decisions. Keep independent `AMP_EN` control with its amplifier default-off pull-down. Use Si5351 I²C RF-output control for routine keying while CLK2 calibration can continue between transmissions. Keep the amplifier off through startup, allow the reference to settle and program/verify the synthesizer before permitting amplification. Actual clock-supply loss requires initialization before reuse; startup and power-loss behavior remain validation work. [TI always-on enable connection](https://www.ti.com/lit/gpn/tps7a20#page=24)
- Include the [GPIO shield's **onboard BS170 amplifier circuit**](../WsprryPico%20GPIO%20Shield/README.md), as locked by the user on 2026-10-06. Reuse its TPS22918 switched-supply topology and separate active-high `AMP_EN` control with a default-off pull-down; adapt the RF input for the Si5351. Its supply source is now the shared selector below, and its output uses the locked DC-blocked SMA/external-LPF arrangement. Power goals/current budget, GPIO, input conditioning, LCSC BOM and band qualification remain open. Keep its drain/bias supply separate from `SYNTH_3V3`. Reannotate amplifier components to avoid collisions with the synth references. The later controls selection below adds a button and LED; the RF-GPIO selector remains unselected. The circuit has not yet been added to the starter.
- Use **amplifier output → series DC-blocking capacitor → SMA → external band-appropriate LPF**, as specified by the user on 2026-10-06. Omit the GPIO shield's paired LPF sockets; no onboard filter bank or filter-control GPIOs are selected. Specify the capacitor and SMA part/footprint and verify this path across 2200 m through 2 m. The shield's SMA output is before external filtering.
- Include **both a shield pushbutton and a shield LED**, as specified by the user on 2026-10-06. Their GPIOs, button action, LED behavior and exact stocked LCSC parts remain open; their inclusion does not select the RF-GPIO header or onboard LPF sockets.
- Include **LSI/CSI LS7366R-S, SOIC-14, LCSC C3827808**, and a GPS PPS connection for optional GPS frequency calibration, as locked by the user on 2026-10-06. Adopt the shared counter/capture architecture and assign **CLK2** to calibration, targeting a verified **one-quarter-reference ratio** and nominal **6.25 MHz** at this shield's **25 MHz** reference. Future firmware applies accepted corrections between transmissions; operation without GPS uses the TCXO with nominal or valid saved calibration. Receiver interface, supply source, PPS-conditioner family and GPIO choices are now locked below. Exact parts, pulse behavior, power sequencing, support BOM, divider verification and qualification remain implementation work. No calibration circuit or firmware has been implemented by this selection.
- Use the [approved external-GPS interface and pin plan](TCXO-SI5351A-DESIGN.md#gps-configuration-locked), as locked by the user on 2026-10-06: an optional **3.3 V NMEA/UART receiver with active-high 3.3 V PPS** and a keyed five-position **3V3 / GND / GPS_TX / GPS_RX / PPS** connector. Assign **GP0 UART0 TX**, **GP1 UART0 RX**, **GP16 PPS**, **GP10 SPI1 SCK**, **GP11 MOSI**, **GP12 MISO**, **GP13 counter chip select** and **GP17 capture notification**. Supply the receiver, counter and SN74LVC1G14 PPS conditioner from **Pico 3V3_OUT, physical pin 36**, keeping their load off `SYNTH_3V3`. GPIO and supply selection are resolved; component specifications, firmware ownership and electrical/RF acceptance remain open.
- Use a **shared three-pad power selector**: outer pads connect to Pico **pin 40 / VBUS** and **pin 39 / VSYS**; the center pad feeds both the clock regulator input and the amplifier's `AMP_5V_IN` boundary before its TPS22918 switch. The user accepted sharing the same selector on 2026-10-06. A narrow, accessible copper link connects VBUS to the center by default; the VSYS-to-center gap is open. Retain the solder-pad arrangement, label it `VBUS / IN / VSYS` and mark the cut point. To select VSYS, power off, cut the default link, verify it is open, then solder VSYS to the center; both power branches change source together. Never close both connections together: that ties VBUS to VSYS and bypasses the Pico's isolation diode. USB is the default nominal 5 V source; external VSYS operation is intended for a regulated nominal 5 V feed with adequate regulator headroom and the documented external-power isolation when USB and external power may coexist. Keep `AMP_EN` independent of the always-on clock supply. No separate amplifier supply connector is selected; validate combined current, selector capacity, voltage drop and noise.
- Preserve the independent `${KIPRJMOD}` libraries for the GPIO shield, synth shield and QRP model project.

## Differences reconciled

| Difference | Reconciled interpretation |
| --- | --- |
| Si5351A in the shield notes versus MS5351M in this chat | Different targets. Preserve the actual MS5351M in the photographed model; use the Si5351A datasheet for the shield. Favoring Hans' design does not change the shield's selected silicon. Fitting an unchanged Rev6 synth module would introduce MS5351M and requires an explicit revision of that choice. |
| KDS identity in the other chat versus functional Y101 here | The selected KDS part has documented pins **1/2 GND, 3 OUT, 4 VCC**. The photo's `25.00BN / D441` marking is consistent with the KDS specification, but does not establish a certified QRP factory ordering code. The photographed model retains its deliberately abstract three-terminal oscillator. A future discrete shield symbol must use the selected KDS part's real four-pad pin map. |
| Unknown C101/C102 versus 10 nF / 1 nF in the proposed circuit | C101/C102 are the photographed module's capacitors and remain unknown. C21 = 10 nF X7R and C22 = 1 nF C0G/NP0 are selected for the shield prototype, following KDS' measurement-circuit values. These are not Hans' verified capacitor BOM. C4 on the Rev6 synth also remains unknown. |
| Completed QRP circuit versus unfinished shield | The QRP project has three editable sheets and readable PDFs. The synth shield has design notes and a proposed SVG, but the synth circuit has not been added to its KiCad schematic or PCB. Neither project's check results substitute for the other's. |
| Rev6 repair wire versus a new shield connection | W1 records the photographed Q1 gate-trace repair. In a new circuit, route the intended connection correctly; an intentional missing trace and repair wire are not design requirements. |
| Prior 5 mA TCXO value versus 1.5 mA | **1.5 mA maximum** is the selected KDS specification value. The other chat's saved design notes already corrected the earlier 5 mA statement. |
| Older U3S 25 MHz warning versus newer Hans documentation | The current U3S listing qualifies 2 m WSPR support by reference frequency. The newer U4B operating manual documents a 25 MHz TCXO, Si5351A, WSPR and 2200 m–2 m coverage. These describe different products and firmware; do not apply the U3S statement as a universal restriction. Keep 25 MHz and the confirmed 2 m WSPR requirement, with shield implementation and measurement still required. See the [dated source comparison](TCXO-SI5351A-DESIGN.md#2-m-wspr-and-the-25-mhz-reference). |

The KDS pin map, marking convention, current limit and measurement circuit were checked against its specification, Serial 2019-0443 dated 2019-07-08. Its numbered pages 1-2 are PDF pages 2-3 because the PDF includes a cover. The family drawing also shows that related DSA and SDNB versions give pin 1 another function. [KDS specification](https://datasheet.lcsc.com/datasheet/pdf/4560f1646e80e1d25a345e540c19e02b.pdf?productCode=C253672), [KDS family drawing](https://www.kds.info/wp-content/uploads/2015/11/dsb321sdn-1-d_pdf_en-1.pdf#page=2)

Select the bus speed and verify rise time at the actual loading; check powered/unpowered behavior with the selected `SYNTH_3V3` rail. The QRP model's documented **1 kΩ** R1-R4 remain unchanged. |
| Compensation continuity | QRP Labs describes its module as analog/no-stepping. KDS' checked specifications do not explicitly guarantee the selected bare part's compensation architecture or maximum correction step. Record the accepted setting for the selected Si5351A revision; do not transfer an MS5351M register assumption. [Datasheet section 4.1.1](https://www.skyworksinc.com/-/media/Skyworks/SL/documents/public/data-sheets/Si5351-B.pdf#page=15), [AN619 register 183](https://www.skyworksinc.com/-/media/Skyworks/SL/documents/public/application-notes/AN619.pdf#page=60) |

The repository's [shared GPS calibration proposal](../design/GPS-FREQUENCY-CALIBRATION.md) describes a 27 MHz baseline, the selected LS7366R-S counter and CLK2 at one-quarter of the reference. The user adopted that counter architecture for this shield on 2026-10-06. Its shield-specific nominal calibration clock is **6.25 MHz** for the selected **25 MHz** reference; verify the divider plan and record the actual ratio in calibration metadata. The shared proposal remains authoritative for the architecture and its own 27 MHz baseline. Do not copy its 6.75 MHz constants or associated wrap/resolution figures unchanged into this shield. Counter inclusion is resolved; the adjacent implementation and qualification requirements remain open.

None of these software results establish fabrication, assembly, oscillator identity or RF performance.
