# Wsprry Pi LPF Board

This design is for the LPF board.

Open [Wsprry-Pi-LPF.kicad_pro](Wsprry-Pi-LPF.kicad_pro) in KiCad. The [schematic PDF](Wsprry-Pi-LPF.pdf) is a reference export; the [filter workbook](<LPF-(C-L-C)-and-DC-Blocking-Filters.xlsx>) contains supporting design calculations.

The project uses its own custom footprint library under `libraries/footprints`. Its referenced `libraries/symbols/New_Library.kicad_sym` and `libraries/symbols/Wsprry-Pi-LPF.kicad_sym` libraries are currently missing.

Treat this design as untested unless a specific revision has documented validation. See the [repository README](../README.md) for KiCad version details, other missing assets, and repository conventions.
