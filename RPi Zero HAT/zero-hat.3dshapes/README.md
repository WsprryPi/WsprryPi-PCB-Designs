# Raspberry Pi HAT socket 3D model

`PinSocket_2x20_P2.54mm_Vertical.step` is the standard KiCad 2×20, 2.54 mm vertical pin-socket model already used by the Raspberry Pi GPIO connector in `Wsprry-Pi-Synth-Univ`. The selectable H1 footprint places it on the underside of the RPi Zero HAT board and aligns it with the 40 electrical pads. Delete or restore H1 independently of the U1 electrical interface. The model file is copied locally so projects created from the template remain self-contained.
